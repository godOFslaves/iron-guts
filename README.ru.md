# IRON GUTS

Оригинальный ретро-вдохновлённый шутер от первого лица, написанный на TypeScript с использованием Three.js.

**Статус:** Ранняя разработка — доступен играбельный прототип.

> [English version](README.md)

## Возможности

- Камера от первого лица с обзором мышью (Pointer Lock API)
- Перемещение WASD с нормализацией диагонального движения
- Движение на основе delta-time для независимости от частоты кадров
- AABB-коллизии со стенами с скольжением вдоль стен
- Обработка столкновений в углах
- Ограничение максимального delta-time для предотвращения «телепортации» после переключения вкладки
- Минималистичная серая тестовая комната
- Полная типизация на TypeScript
- Автоматические тесты логики физики

## Управление

| Клавиша | Действие |
|---------|----------|
| WASD / Стрелки | Перемещение |
| Мышь | Обзор |
| Клик | Захват мыши (старт) |
| ESC | Освободить мышь |

## Требования

- Node.js 22 LTS или новее
- Современный браузер (Chrome, Firefox, Edge, Safari)

## Установка

```bash
npm install
```

## Запуск

```bash
npm run dev
```

Откройте `http://localhost:5173` в браузере.

## Сборка

```bash
npm run build
```

Результат в `dist/`.

## Тесты

```bash
npm run test
```

## Линтинг

```bash
npm run lint
```

## Структура проекта

```
├── src/
│   ├── config/       # Константы игры (размеры комнаты, параметры игрока)
│   ├── core/         # Игровой цикл, ввод, физика, аудио
│   ├── entities/     # Сущность игрока
│   ├── levels/       # Данные уровней
│   ├── rendering/    # Настройка сцены Three.js
│   ├── ui/           # HUD и меню (HTML/CSS overlay)
│   ├── weapons/      # Реализации оружия
│   └── utils/        # Вспомогательные функции
├── tests/            # Юнит-тесты Vitest
├── public/           # Статические файлы
├── index.html        # Точка входа HTML
├── vite.config.ts    # Конфигурация Vite
├── tsconfig.json     # Конфигурация TypeScript
├── eslint.config.js  # Конфигурация ESLint
├── vitest.config.ts  # Конфигурация Vitest
├── package.json      # Зависимости и скрипты
└── .gitignore        # Исключаемые файлы
```
