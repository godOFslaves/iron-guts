# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in IRON GUTS, please report it responsibly:

1. **Do not** open a public GitHub Issue for security problems.
2. **Do not** publish exploit details in public channels.
3. Open a private security advisory via GitHub's [Security](https://github.com/godOFslaves/iron-guts/security) tab, or contact the maintainer directly.

We aim to acknowledge and address reported vulnerabilities promptly.

## What to Avoid

- Do not commit secrets, tokens, passwords, or private keys to the repository.
- Do not share personal information or credentials in issues or PRs.
- Do not test vulnerabilities against the live GitHub Pages deployment in a way that could disrupt service.

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |
| < 0.1   | No        |
